# Pixel Office

A pixel-art home office theme for Claude Code in the desktop and mobile apps.
In light mode it is a sunny day: sunbeams on the wall, blue sky and trees outside the window.
In dark mode it is night: two warm lamps glowing, a moon, stars and a city skyline.
An orange pixel buddy sits at the desk typing on a laptop, with plants, books and a steaming mug around it.
It also sets matching colors for the whole app: warm pink-white by day, slate blue by night.

像素风家庭办公室主题：浅色模式是阳光白天，深色模式是台灯夜晚，并配套整套界面配色。

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install pixel-office --marketplace gg18966141298-crypt/pixel-office
```

Answer `y` to add the marketplace, then pick a scope (user scope is first; press Enter).

From a shell:

```bash
claude plugin install pixel-office --marketplace gg18966141298-crypt/pixel-office
```

In the desktop app: click + next to the prompt box, then Plugins, Add marketplace with `gg18966141298-crypt/pixel-office`, then Add plugin.

## Use

The theme follows the app's light/dark setting. To pin one scene:

- `/office night` – always the night scene
- `/office day` – always the day scene
- `/office auto` – follow the app again

The backdrop draws in the desktop and mobile apps; the terminal uses the colors only.
The scene includes subtle animations (blinking, typing, steam, swaying plants, drifting clouds, twinkling stars); whether they play depends on your app version.

## Editing the scene

The scene is generated by `tools/gen-scene.mjs`. Change coordinates or colors there, then run `node tools/gen-scene.mjs` to rewrite `hooks/scene.ts`.
